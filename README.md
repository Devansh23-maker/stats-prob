# 📊 Statistics & Probability for Data Science

This repository documents my **structured learning journey of Statistics and Probability**, focused on **data science and analytics applications**.

Instead of only theory, this repo emphasizes:
- statistical thinking
- simulations
- interpretation of results
- real-world relevance

The goal is to build **strong analytical foundations** required for data analysis, machine learning, and economic modeling.

## 📅 Day 1 — Probability Foundations

### Concepts Covered
- Random experiments
- Sample space
- Random variables
- Mean (Expected Value)
- Variance & Standard Deviation
- Normal distribution

### Experiments
- Dice roll simulation
- Coin toss simulation
- Normal distribution generation

### Key Learning
> Probability models uncertainty and randomness, which is the foundation of all statistical analysis and machine learning.

## 📅 Day 2 — Statistics Core & Applied Thinking

### Concepts Covered
- Descriptive statistics (mean, variance, std)
- Correlation analysis
- Lag analysis (delayed effects)
- Rolling averages (trend detection)
- Z-scores (standardization & anomalies)

### Experiments Include
- Statistical summary of simulated data
- Distribution visualization
- Correlation analysis with noise
- Lagged correlation
- Rolling trend smoothing
- Outlier detection using Z-scores

### Key Learning
> Statistics is not about formulas — it is about understanding relationships, trends, and abnormal behavior in data.
